# noobchain

A hands-on blockchain implementation built with Java — learn how cryptocurrencies work under the hood.

## What You'll Learn

- **Proof-of-Work Mining** — See how miners compete to solve cryptographic puzzles
- **Digital Wallets** — Generate key pairs and sign transactions securely
- **Transaction Processing** — Understand UTXOs and how funds move between wallets
- **Chain Integrity** — Explore how blocks link together to prevent tampering

## Getting Started

1. Clone the repository
2. Open in your favorite Java IDE
3. Run `NoobChain.java` to see the blockchain in action

Built for developers curious about blockchain fundamentals.
